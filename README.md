# 户型效果预览 Agent (home-design-agent)

输入**户型图**和**装修需求**，自动生成**效果预览**用于谈单；客户选定后再生成 **3D 可漫游模型**。

面向**设计师/销售当场驱动**的场景：要快、能现场改、图不跑偏。

## 核心思路（路线 B）

识别 → 结构化方案(Scheme) → 双通道出图：

1. **① 户型识别** — 视觉模型把户型图读成结构化数据（房间/尺寸/门窗/承重墙）
2. **② 需求解析** — 选项框 + 口述 → 结构化需求
3. **③ 方案生成 ★** — LLM 基于户型+需求生成结构化方案 Scheme（系统唯一"大脑"）
4. **④ 彩平图** — 从 Scheme 程序化渲染，零 AI，保「准」
5. **⑤ 实景图** — 商业图像 API + 构图参考，保「美」
6. **⑥ 3D 漫游** — 阶段二，Scheme 实例化成 3D（Three.js）
7. **⑦ 存储 & 案例库** — 按 `小区+户型+风格` 检索，给客户看别人家怎么装

## 分期

- **Phase 0（MVP）**：①②③④⑤，单户型跑通、当场出预览
- **Phase 1**：⑦ 存储 + 案例库
- **Phase 2**：⑥ 3D 可漫游
- **Phase 3**：自建 SD+ControlNet 替换 ⑤
